# 사용 가이드

[English](user-guide.en.md)

화면 곳곳의 **?** 버튼에 짧은 설명이 있습니다. 이 문서는 작업 순서와 알아 둘 제한을 정리합니다.

## 처음 시작하기

1. `./install.sh`로 설치하고 `./start.sh`로 실행합니다. 주소는 `http://127.0.0.1:18185`입니다.
2. **작업실 홈**의 '시작하기' 목록을 따라 합니다: 음성 모델 준비 → 내 목소리 등록 → 첫 음성 만들기. 각 단계는 실제 상태에 따라 자동으로 체크됩니다.
3. 설정 → 모델에서 영역별 기본 모델을 확인합니다. 설치되지 않은 모델은 카드에 설치 명령이 표시됩니다.

`./start.sh`는 모델이 없으면 이 프로젝트 안에 자동으로 내려받고(음성·받아쓰기는 `backend/models/`, 노래 커버·효과음은 Apple Silicon에서만 `backend/vendor/`와 `backend/models/`), 포트가 사용 중이면 그 프로그램을 종료한 뒤 시작합니다(`--core-models`, `--no-models`, `--no-kill`로 조절할 수 있습니다).

모델을 나중에 추가하려면 저장소 루트에서 실행합니다.

```bash
./download-models.sh --tts            # 음성(VoxCPM2)
./download-models.sh --stt            # 받아쓰기(Whisper)
./download-models.sh --soulx-singer   # 노래 커버 (Apple Silicon)
./download-models.sh --sfx            # 효과음 (Apple Silicon)
```

설치한 모델은 `backend/.env`에서 자동으로 켜집니다.

## 목소리 등록

`목소리 클론 → 목소리 등록`에서 기준 음성을 준비합니다. 세 가지 방법이 있습니다.

- **파일**: 오디오 파일을 선택합니다.
- **녹음**: 마이크로 5~10초 정도 녹음합니다.
- **YouTube·Instagram**: 영상 주소를 붙여 넣습니다.

### 링크에서 가져오기

1. 주소를 입력하고 **확인**을 누르면 제목과 길이를 먼저 보여 줍니다.
2. **가져올 구간**(선택)에 시작·끝을 `90` 또는 `1:30` 형식으로 입력하면 그 구간만 내려받습니다. 기본 한도는 한 번에 60분이며, 구간을 지정하면 그 구간의 길이에 한도가 적용됩니다.
3. **배경음·효과음을 줄이고 말소리 중심으로 가져오기**를 켜면 말소리를 정리해서 가져옵니다.
4. **주소에서 가져오기**를 누르면 오디오를 WAV로 변환해 `backend/storage/uploads/`에 저장합니다.

단일 공개 게시물만 지원하며 프로필·재생목록·컬렉션은 지원하지 않습니다. 로그인이 필요한 본인 게시물은 Netscape 형식 쿠키 파일 경로를 지정할 수 있습니다.

```env
# backend/.env
CLONE_VOICE_MEDIA_IMPORT_MAX_DURATION_SECONDS=3600
CLONE_VOICE_MEDIA_IMPORT_COOKIE_FILE=
```

쿠키 파일은 저장소 밖에 두고 권한을 제한하며 Git에 추가하지 마세요. 서비스가 접근 방식을 바꾸면 최신 `yt-dlp`로도 일시적으로 실패할 수 있습니다.

### 쓸 구간 고르기

가져온 오디오는 전체 위치 파형과 확대 파형으로 구간을 고릅니다. 5~10초의 또렷한 말소리가 좋습니다.

1. **말소리 구간 찾기**: 전체 파일에서 말소리·음악·노래 위치를 표시하고 후보를 제안합니다. Apple Silicon Mac에서는 SoundAnalysis를 쓰고, 그 밖의 환경에서는 음량 기준으로 표시하므로 직접 들어 보고 고르세요.
2. **대본으로 구간 찾기**: 선택 주변 최대 30초를 받아써서 문장을 누르면 음성과 대본이 함께 선택됩니다.
3. 선택 구간을 듣고 이름과 대본을 확인해 저장합니다. 구간을 바꾼 뒤에는 대본이 현재 구간의 것인지 확인해야 저장됩니다.

받아쓰기 방식은 설정 → 일반에서 정합니다. Mac에서는 Apple Speech가 기본이고 그 밖에는 Whisper를 씁니다.

## 음성 만들기

1. `목소리 클론 → 음성 만들기 → 새 대본`에서 원본 언어와 글을 입력합니다.
2. **다른 언어로 만들기**에서 언어를 추가하면 자동 번역하거나 빈 탭에 직접 쓸 수 있습니다. 이미 있는 번역본은 덮어쓰기를 고르지 않으면 유지합니다.
3. 오른쪽 **음성 설정**에서 목소리·속도·품질·모델을 고릅니다. **발음 사전**으로 `API → 에이피아이`처럼 읽는 법을 지정합니다(원문은 그대로, 합성할 때만 치환).
4. **짧게 미리 듣기**로 앞부분을 확인한 뒤 **음성 만들기**를 누릅니다. 생성은 한 번에 1개씩 대기열로 처리하며 다른 화면으로 이동해도 계속됩니다.
5. 결과는 WAV·MP3·TXT 또는 제작 패키지 ZIP으로 내려받습니다. ZIP에는 음성, 원문과 발음 교정문, 생성 설정이 들어 있습니다.

`⌘S / Ctrl+S`로 저장합니다. 저장하지 않은 마지막 초안 한 건은 이 브라우저에 임시 보관되어 **초안 복원**으로 되살릴 수 있습니다.

## 사운드 만들기

프로젝트(게임·영상·환경음)를 만들고 사운드별로 프롬프트·길이·생성 설정을 저장합니다. 예제 프롬프트 12개로 시작할 수 있으며 예제에는 미리 만든 오디오가 없습니다.

다시 생성하면 기존 결과를 보존하고 새 버전을 추가합니다. 버전별 프롬프트·제외 요소·seed를 확인하고 `이 설정으로 다시 만들기`, `비슷하게 만들기`로 이어갈 수 있습니다. 프로젝트는 로컬 서버에 저장되며, 삭제해도 생성된 파일은 파일 보관함에 남습니다. 효과음 모델이 없어도 프로젝트와 프롬프트는 저장할 수 있습니다.

## 노래 커버

`노래 커버`는 원곡의 멜로디와 박자를 유지하면서 보컬을 등록한 목소리로 바꿉니다. 원곡 파일을 고르거나 YouTube·Instagram 주소에서 가져오고, 파형에서 구간을 정한 뒤 대상 목소리를 고릅니다. 보컬 자동 분리, 반주 합성, 음역 자동 조정은 변환 설정에서 켜고 끕니다.

결과 품질은 기준 샘플과 원곡에 크게 좌우됩니다. 잡음과 반주가 적은 기준 샘플을 쓰고, 먼저 보컬이 분명한 30~60초 구간으로 확인한 뒤 전체를 변환하세요.

## 대화 오디오 (보조 도구)

설정 → 일반 → **보조 도구 표시**를 켜면 나타납니다.

1. **AI 대화 만들기**에서 주제를 적거나 자료를 붙여 넣고, 형식(깊이 탐구·인터뷰·토론·빠른 브리핑)과 2~4명의 화자, 길이를 정합니다. 영상 링크에서 원문을 가져올 수도 있습니다.
2. 편집기에서 화자별 목소리·톤, 문장별 속도와 쉼, 효과음 큐를 고칩니다.
3. 대본을 직접 가져올 때는 `화자: 대사`, `화자 [tone: 밝게]: 대사`, `[sfx: 짧은 전환음]` 형식을 씁니다(한국어 `톤`, `효과음`도 인식).
4. **대화 오디오 생성**으로 만들고 WAV·MP3·TXT·SRT·ZIP으로 내려받습니다.

프로젝트는 서버에 자동 저장되며 JSON으로 백업·복원할 수 있습니다. AI 초안은 사실 검증을 대신하지 않으니 공개 전에 원문과 대조하세요.

## 파일 보관함

등록 목소리와 생성 결과(TTS·대화 오디오·노래 커버·효과음)를 한곳에서 다시 듣고 내려받습니다. 효과음·노래 커버의 일부 프로젝트 정보는 이 브라우저의 `localStorage`에 있어 다른 브라우저에서는 연결 정보가 일부 보이지 않을 수 있습니다.

## 설정

### 일반

표시 언어, 시작 화면, 기본 원본 언어, 보조 도구 표시, 받아쓰기 방식, 번역 방식을 정합니다. Apple 번역 옵션은 Mac에서만 표시됩니다.

### 모델

영역(음성·음악·커버·효과음)별로 모델 목록, 상태, 기본 모델, 사용 여부, 순서를 관리합니다. 음성·커버 영역은 최소 한 개가 켜져 있어야 합니다. 카드를 펼치면 장치·음질·라이선스·지원 환경과 설치 명령을 볼 수 있습니다.

### AI 연결

대본 작성·번역·제작 도움에 쓸 텍스트 AI를 이름별로 등록합니다. 음성 생성과 목소리 복제에는 필요하지 않습니다.

1. **연결 추가**에서 직접 입력하거나 LM Studio·Ollama·DeepSeek·OpenRouter·Gemini·Claude·OpenAI·NVIDIA 프리셋을 고릅니다(주소와 API 형식만 채워지며 모델 ID는 직접 고릅니다).
2. 인증 방식과 키를 입력합니다. 새 키는 Mac Keychain에 저장하고, 실패하면 자동으로 파일 저장으로 바꾸지 않습니다. 사용자가 **권한 제한 파일**을 고른 경우에만 0600 파일에 저장합니다.
3. 모델을 직접 추가하거나 저장 후 **모델 목록 불러오기**로 고르고, **응답 테스트**로 확인합니다(외부 API는 소량의 비용이 들 수 있습니다).
4. **기본 AI**와 **작업별 AI**(번역·대본·제작 도움)를 정합니다.

지원 형식은 OpenAI Chat Completions, Anthropic Messages, OpenAI Responses이며 비스트리밍 텍스트 응답만 사용합니다. **로컬 전용**(기본)이 켜져 있으면 외부 API 호출을 모두 차단하고, 실패 시 다른 제공처로 자동 재전송하지 않습니다.

```env
# backend/.env — 이전 방식의 단일 로컬 연결
CLONE_VOICE_LLM_BASE_URL=http://127.0.0.1:11434/v1
CLONE_VOICE_LLM_MODEL=qwen3:4b
CLONE_VOICE_LLM_API_KEY=ollama
```

AI 연결 탭 아래의 **제작 시스템 프롬프트**에서 효과음·음악·노래·커버 도움에 쓰는 지침을 수정·복원할 수 있습니다. 음악·노래는 프롬프트와 가사 초안만 만들며 완곡 오디오를 생성하지 않습니다.

### Mac 내장 번역

Apple Silicon Mac, macOS 26 이상, Apple Intelligence 온디바이스 모델이 준비되어 있어야 합니다. 처음 확인할 때 작은 Swift 도우미를 컴파일하므로 Command Line Tools 또는 Xcode가 필요합니다. 설정 → 일반의 **번역 확인**으로 실제 번역을 시험해 볼 수 있습니다.

## 저장 위치와 포트

업로드, 생성 결과, SQLite DB는 기본적으로 `backend/storage/`에 저장됩니다. `CLONE_VOICE_VOICE_DIR`, `CLONE_VOICE_UPLOAD_DIR`, `CLONE_VOICE_OUTPUT_DIR`, `CLONE_VOICE_CONTENT_DIR`로 위치를 나눌 수 있습니다.

다운로드한 모델은 `backend/models/`에 저장됩니다(`CLONE_VOICE_VOXCPM_CACHE_DIR`이나 `~/.cache`에 이미 있는 모델은 다시 받지 않고 그대로 사용). 기본 포트는 다른 개발 서버와 겹치지 않도록 프론트엔드 `18185`, 백엔드 `18109`로 잘 쓰지 않는 번호입니다. `./start.sh`는 이 포트를 쓰는 프로그램이 있으면 종료하고 시작하며, `--no-kill`을 주면 종료하지 않고 멈춥니다.

```bash
BACKEND_PORT=8010 FRONTEND_PORT=5190 PUBLIC_API_BASE=http://127.0.0.1:8010 ./start.sh
```

## 문제 해결

- **모델이 '설치 필요'로 표시됩니다.** 카드의 설치 명령을 실행하거나 `./install.sh`를 다시 실행하세요. 설치한 모델은 `backend/.env`에서 자동으로 켜집니다.
- **포트가 사용 중이라고 나옵니다.** `./start.sh`는 기본으로 그 포트를 쓰는 프로그램을 종료하고 시작합니다. `--no-kill`을 줬다면 위처럼 다른 포트를 지정하거나 해당 프로그램을 직접 종료하세요.
- **링크 가져오기가 실패합니다.** 공개 게시물인지, 로그인이 필요한지 확인하세요. 서비스 변경으로 일시적으로 실패하면 `uv sync`로 `yt-dlp`를 갱신해 보세요.
- **노래 커버·효과음을 설치할 수 없습니다.** 두 모델은 현재 Apple Silicon Mac용입니다.
